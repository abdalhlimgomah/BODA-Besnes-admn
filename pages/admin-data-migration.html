مزامنة كل السيرفرات بالكامل تلقائي 3-Way

يفحص كل السيرفرات المتاحة، ويحسب الناقص عند كل سيرفر مقارنةً بالأكبر. المزامنة تعمل عبر سيرفر منسّق (السيرفر النشط المسجّل فيه الدخول): يسحب أولًا صفوف السيرفرات الأخرى الناقصة عنده، ثم يدفع بياناته الكاملة إليها — حتى تصبح كل السيرفرات متطابقة (وضعية تحديث + إضافة). النقل بالمراحل وقابل للاستئناف ولا يتوقف عند الجداول الضخمة.

للنسخ إلى مشروع جديد خالص

  1. انقل هيكل الجداول (schema) للمشروع الجديد — الأسهل بسكريبت migrate-supabase.sh القديم أو أنشئه نسخة من الأساسي.
  2. شغّل الكود بالأسفل مرة واحدة في SQL Editor للمشروع الجديد (يجهز دوال الاستيراد والعدادات).
  3. من سطر الأوامر أضف المشروع الجديد لسر الروابط (بالصيغة name|url|key، كل هدف مفصول بـ;): supabase secrets set MIG_TARGETS='new|https://REF.supabase.co|sb_secret_...' --project-ref REF في المشروع المصدر.
  4. ارجع للصفحة، اختر المصدر ثم هدف new ووضعية "نسخة كاملة".
