تحديث بيانات الجلسة

القيمة من كوكيز المتصفح بعد تسجيل الدخول في aff.ven-door.com — تأخذها من تبويب Application > Cookies
كوكيز XSRF-TOKEN من نفس تبويب Application > Cookies
توكن الحساب من auth.thunderbit.com — يُحفظ كمرجع فقط ولا يُستخدم في السحب

استخراج بيانات الجلسة من متصفحك

الصق هنا طلب الـ Network الكامل (tab Network → الطلب load_data أو أي طلب للصفحة الرئيسية → Copy as cURL​) أو نص الكوكيز — سيتم استخراج القيم تلقائياً.

جلب منتجات Vendoor

يُسحب الكتالوج (كروت المنتجات كاملة) ثم يُضيف التفاصيل والجلسة المسبقة للمقايس في نفس جدول taager_products بتعريف vendor_ — لا تلمس منتجات تاجر.

0 = جلب الكتالوج كاملاً حتى آخر صفحة تلقائيًا (مُوصى به) — ضع رقمًا لتحديد عدد صفحات محدد ومقترح
0 = بدون تفاصيل (سريع) — التفاصيل تُملأ بالتتابع: كل جولة تكمّل المنتجات الناقصة دون إعادة ما تم جلبُه
يُحفظ مع بقية البيانات تلقائياً — مطلوب فقط إذا عيّنت VENDOR_SYNC_SECRET على الخادم

مزامنة مع Supabase Secrets

تحديث بيانات جلسة Vendoor في Supabase Secrets (مطلوبة لـ Edge Function) — يولد ملف .bat ينفّذ الأمر تلقائياً.

الأمر اليدوي: supabase secrets set VENDOR_COOKIE_SESSION="..." VENDOR_COOKIE_XSRF="..."

آخر منتجات Vendoor المستوردة

كيفية الحصول على بيانات الجلسة

  1. سجّل الدخول في aff.ven-door.com من متصفحك.
  2. افتح DevTools (F12) → تبويب Application → Cookies → موقع aff.ven-door.com.
  3. انسخ قيمة الكوكية laravel_session وضعها في حقل Cookie Session، وقيمة XSRF-TOKEN في حقل XSRF Token.
  4. أو: تبويب Network → اعمل Refresh → اضغط على أي طلب → Copy as cURL والصق النص كاملاً في صندوق "استخراج".
  5. اضغط "فحص الجلسة" للتأكد، ثم "جلب الآن".
  6. ملاحظة: الجلسة تنتهي بعد نحو ساعتين — يُعاد استخراجها عند الحاجة.
