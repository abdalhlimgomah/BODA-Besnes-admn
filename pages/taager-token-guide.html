كيفية الحصول على توكن متجر تاجر

شرح مفصّل بالصور لاستخراج بيانات الدخول إلى API تاجر

1 سجّل الدخول إلى تاجر

افتح المتصفح واذهب إلى taager.com وسجّل الدخول بحسابك (بريد إلكتروني أو Google).

صفحة تسجيل الدخول إلى taager.com

تأكد من أنك تستخدم نفس الحساب المرتبط بمتجرك على تاجر.

2 افتح أدوات المطور (Developer Tools)

بعد تسجيل الدخول، افتح أدوات المطور في المتصفح:

  • Google Chrome / Edge: اضغط F12 أو Ctrl+Shift+I (Windows) / Cmd+Option+I (Mac)
  • Firefox: F12 أو Ctrl+Shift+I
نافذة أدوات المطور مفتوحة على tab "Application"

3 اذهب إلى تبويب Application > Local Storage

في أدوات المطور:

  1. اختر تبويب "Application" (أو "Storage" في Firefox)
  2. من القائمة اليمنى، اختر "Local Storage"
  3. اختر نطاق https://www.taager.com
Local Storage لموقع taager.com — ابحث عن المفاتيح المطلوبة
💡 نصيحة: يمكنك كتابة tgr في خانة Filter للعثور على المفاتيح بسرعة.

4 استخرج الـ JWT Token (API Key)

في قائمة Local Storage، ابحث عن المفتاح tgr--usr:

  1. انقر نقراً مزدوجاً على قيمة (Value) المفتاح tgr--usr
  2. ستظهر قيمة طويلة — انسخها بالكامل (تبدأ بـ eyJ)
  3. هذه هي الـ API Key (JWT Token)
قيمة tgr--usr تبدو هكذا: eyJhbGciOiJIUzI1NiIs...
⚠️ مهم: التوكن صالح لمدة 24 ساعة تقريباً. بعد انتهائه، يجب استخراج توكن جديد. مع ذلك، تطبيقنا يحاول جلب التوكن تلقائياً عند انتهائه.

5 استخرج الـ Session Key

في نفس قائمة Local Storage، ابحث عن المفتاح tgr--usr-s:

  1. ستجد قيمة أقصر (عادة 32 حرفاً)
  2. انسخ هذه القيمة — هذا هو الـ Session Key
قيمة tgr--usr-s: Wq3eK8uYcmb8cFtZTGAOiBw68Llm1sH9

6 استخرج الـ Taager ID

يمكنك الحصول على معرف التاجر بطريقتين:

  1. من التوكن نفسه: قيمة tgr--usr تحتوي على TaagerID مشفر داخلها — يمكنك فك التشفير وفك الـ JSON لرؤيته
  2. من لوحة تحكم تاجر: اذهب إلى الإعدادات في حساب تاجر، ستجد "Merchant ID" أو "Taager ID"
  3. أسهل طريقة: استخدم موقع jwt.io — الصق التوكن هناك وسترى TaagerID في الـ JSON
jwt.io يعرض محتوى التوكن — ابحث عن "TaagerID"
💡 نصيحة: معرف التاجر لا يتغير غالباً. احفظه في مكان آمن.

7 أدخل البيانات في لوحة التحكم

الآن عد إلى صفحة "إدارة توكن تاجر" في لوحة التحكم:

  1. الصق الـ JWT Token في حقل API Key
  2. الصق الـ Session Key في الحقل المخصص
  3. أدخل Taager ID في الحقل المخصص
  4. اضغط "حفظ البيانات"
⚠️ مهم: بعد الحفظ، سيتم تخزين البيانات في Supabase table app_settings، وسيقوم المتجر بجلبها تلقائياً.

8 التحقق من سريان التوكن

بعد الحفظ:

  • اذهب إلى المتجر وافتح أي صفحة — ستظهر بيانات تاجر خلال ثوانٍ
  • في صفحة "إدارة توكن تاجر"، ستظهر صلاحية التوكن (تاريخ الانتهاء)
  • إذا كان التوكن منتهي الصلاحية، كرر الخطوات 1-6 لاستخراج توكن جديد

تجديد التوكن التلقائي

التطبيق يدعم تحديث التوكن تلقائياً عبر:

  • ملف taager_token_refresh.py — يستخدم Selenium لتسجيل الدخول إلى تاجر واستخراج التوكن
  • يُشغّل يومياً عبر Scheduled Task في Windows
  • يُحدّث التوكن في Supabase Secrets لـ Edge function

إذا أردت إعداد التحديث التلقائي:

🔧 للتشغيل اليدوي: شغّل ملف taager_token_refresh.py من مجلد المشروع.
🔄 للتشغيل اليومي: شغّل setup-auto-refresh.ps1 مرّة واحدة لإنشاء Scheduled Task.

مزامنة Edge Function

الـ Edge function (taager-proxy) يحتاج البيانات في Supabase Secrets أيضاً:

  1. افتح terminal في مجلد المشروع
  2. شغّل الأمر التالي:
    supabase secrets set TAAGER_JWT_TOKEN="<token>" TAAGER_TAAGER_ID="<id>" TAAGER_SESSION_KEY="<key>"
  3. أعد نشر الـ Edge function:
    supabase functions deploy taager-proxy --no-verify-jwt
⚠️ مهم: إذا لم تحدّث Supabase Secrets و Edge function، فإن الطلبات عبر الـ proxy قد تفشل.
💡 ملاحظة: التطبيق يستخدم الـ proxy كخيار أوّل. إذا فشل، يحاول الاتصال المباشر بـ Taager API باستخدام البيانات الموجودة في app_settings. لذلك حتى لو لم تحدّث الـ proxy، المتجر قد يعمل لكن بشكل أبطأ.
