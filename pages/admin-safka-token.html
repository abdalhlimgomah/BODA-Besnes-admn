مزامنة مع Supabase Secrets

تحديث SAFKA_AUTH_TOKEN و SAFKA_ACCOUNT_ID و SAFKA_API_BASE ثم إعادة نشر Edge Function safka-proxy. يتم توليد ملف .bat ينفّذ الأمرين تلقائياً.

الأمر اليدوي:
supabase secrets set --project-ref msgqzgzoslearaprgiqq SAFKA_AUTH_TOKEN="..." SAFKA_ACCOUNT_ID="..." SAFKA_API_BASE="..." supabase functions deploy safka-proxy --project-ref msgqzgzoslearaprgiqq --no-verify-jwt

الحقل في متجرك المصدر في Safka طريقة التحويل / الحفظ
اسم المنتج name يُحفظ مباشرة في name بعد فك ترميز HTML.
الوصف description (HTML) يُحوّل إلى نص نظيف في description، ويُستخدم أيضاً لاستخراج التفاصيل السريعة وأفكار المحتوى.
معلومات عامة category.name، merchant.name، product_type، labels، min_quantity، availability_type تُحفظ في category وbrand وvendor وsafka_product_type وsafka_labels وsafka_min_quantity وsafka_availability_type.
السعر sale_price (تكلفة المورد) + note (سعر البيع المقترح) + properties[].sale_price افتراضياً price = sale_price. عند تفعيل خيار «سعر البيع المقترح» يصبح price هو المقترح. التكلفة والمقترح يُحفظان دائماً في safka_cost_price وsafka_suggested_price.
خصومات الكميات discount_rules[] — qty، sale_price (سعر الوحدة بعد الخصم)، discount، name تُحفظ في جدول safka_quantity_discounts (صف لكل كمية) مع حساب النسبة وإجمالي قبل الخصم.
الكمية / المخزون properties[].value للمتغيرات التي is_available !== false، وavailability_type يُجمع مخزون كل المتغيرات في stock. إذا كان availability_type = unavailable أو لا توجد متغيرات متاحة تصبح الكمية 0. الحالة: out_of_stock / low_stock / in_stock.
الصور images[] + image كل الصور الفريدة تُحفظ في images، وأول 8 صور في image1..image8 مع image. الروابط كاملة بعد إضافة CDN.
كود المنتج barcode يُحفظ في safka_code كما هو (كود Safka الحقيقي).
الفيديو لا يوجد حقل فيديو في Safka يُترك videos = [] للتوافق مع نفس شكل taager_products. أزرار الفيديو معطّلة، والفيديو غير محسوب في اكتمال المنتج.
تفاصيل سريعة / أفكار محتوى / طريقة استخدام description + faqs[] تُستخرج تلقائياً: أول فقرة مفيدة للتفاصيل السريعة، قسم المميزات لأفكار المحتوى، وقسم طريقة الاستخدام أو سؤال/جواب مطابق من الـ FAQ. يمكن تعديلها يدوياً من صفحة التدقيق.

الحقول التي لا يوفّرها Safka مباشرة (الفيديو، بعض تفاصيل المحتوى) تبقى بقيم افتراضية أو تُستخرج من الوصف، ويمكن تعديلها يدوياً من صفحة التدقيق.

خطوات التشغيل لأول مرة

  1. شغّل ملف sql/create_safka_products.sql في Supabase SQL Editor (مرة واحدة) — ينشئ safka_products وsafka_quantity_discounts وsafka_settings.
  2. احفظ التوكن هنا (يُحفظ في safka_settings) ثم اضغط "تحديث Supabase Secrets" لنسخه إلى Secrets أيضاً.
  3. افتح ملف .bat الناتج لإعداد الـ Secrets ونشر safka-proxy.
  4. ارجع هنا واضغط "اختبار الاتصال بـ Safka" — يجب أن يظهر ping.ok = true.
  5. افتح صفحة تدقيق Safka واضغط "سحب جميع المنتجات من Safka".
